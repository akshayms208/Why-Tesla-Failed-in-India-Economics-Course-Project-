# Empirical Investigation of Tesla's First-Year Market Penetration in India (2025--2026)

This repository contains the secondary datasets, Ordinary Least Squares (OLS) econometric regression models, counterfactual tariff simulations, and visualization script (`Economics_course_project.py`) for the empirical research project investigating **why Tesla Inc. failed to cross the** $1,000$**-unit annual sales threshold during its first year of operations in India (September 2025 -- August 2026)**.

## Executive Summary & Research Question

While India's domestic electric passenger vehicle (e-PV) sector recorded nearly $98\%$ year-on-year growth between 2025 and 2026---reaching $35,995$ monthly registrations in September 2026---Tesla Inc. registered only $699$ **vehicles** during its first $12$ months of Indian retail deliveries (September 2025 -- August 2026) and $990$ **vehicles** across its first $13$ months (through September 2026).

This study empirically tests the hypothesis that India's Completely Built Unit (CBU) import tariff regime ($70\%$--$100\%$ Basic Customs Duty plus Social Welfare Surcharge and GST) inflated Tesla's landed showroom price to an average of $3.55\times$ the weighted average price of domestic electric SUVs, creating a structural price-competitiveness barrier that outweighed macroeconomic EV adoption spillovers and national public charging expansion.

### Core Research Objectives

1. **Price Sensitivity (**$X_1$**):** Quantify the impact of Tesla's ex-showroom pricing ($\text{Rs. } 59.89\text{ Lakh}$ from September 2025 to May 2026, revised to $\text{Rs. } 50.89\text{ Lakh}$ in June 2026) on monthly Vahan vehicle registrations ($Y_t$).

2. **Tariff Distortion (**$X_2$**):** Decompose the landed tax markup ($92.0\%$ initially; $63.1\%$ post-price cut) generated by India's $70\%$ CBU customs tariff relative to the $5\%$ GST regime applied to domestically manufactured EVs.

3. **Cross-Brand Price Competitiveness (**$X_3$**):** Estimate the constant-elasticity demand sensitivity of Indian EV buyers to the relative price ratio between Tesla and localized incumbents (Tata Motors, JSW MG Motor, Mahindra, and VinFast).

4. **Counterfactual Policy Simulation:** Project Tesla's annualized Indian demand across customs tariff rates from $0\%$ to $100\%$ and evaluate four discrete policy scenarios, including the Government of India's $15\%$ concessional duty under the *Scheme to Promote Manufacturing of Electric Passenger Cars in India* (SPMEPCI) and local Completely Knocked Down (CKD) assembly.

## Econometric Methodology

### 1. Model 1: Linear OLS Specification

Estimates the raw unit change in monthly Tesla registrations per $\text{Rs. } 1\text{ Lakh}$ change in vehicle price while controlling for domestic EV adoption and public charging infrastructure:

$$
Y_t = \beta_0 + \beta_1 X_{1,t} + \gamma_1 C_{1,t} + \gamma_2 C_{2,t} + \varepsilon_t
$$

### 2. Model 2: Log-Log Elasticity OLS Specification

Dynamically log-transforms the variables ($\ln Y_t, \ln X_{3,t}, \ln C_{1,t}, \ln C_{2,t}$) to estimate constant-elasticity percentage demand sensitivity with respect to the relative price competitiveness ratio ($X_{3,t}$):

$$
\ln(Y_t) = \alpha_0 + \eta_3 \ln(X_{3,t}) + \theta_1 \ln(C_{1,t}) + \theta_2 \ln(C_{2,t}) + u_t
$$

### 3. Counterfactual Tariff-Price Simulation

Models the landed ex-showroom price $X_1(X_2)$ as a function of the statutory import customs duty rate $X_2 \in [0\%, 100\%]$, Social Welfare Surcharge ($\text{SWS} = 10\%$), and GST ($\tau_{\text{GST}} = 5\%$):

$$
X_1(X_2) = P_{\text{CIF}} \times \left[1 + X_2(1 + \text{SWS})\right] \times (1 + \tau_{\text{GST}}) + m
$$

## Installation & Usage

### 1. Clone the Repository

```
git clone https://github.com/akshayms208/Economics-course-project.git
cd Economics-course-project

```

### 2. Set Up Virtual Environment & Install Dependencies

Ensure `requirements.txt` contains `numpy`, `pandas`, `statsmodels`, and `matplotlib`:

**Windows (PowerShell):**

```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

```

**Ubuntu / Linux:**

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

```

### 3. Run the Script

```
python Economics_course_project.py

```

This prints the full dataset, descriptive statistics, competitor comparison table, and both OLS regression summaries to the console, saves `jupyter_ols_and_simulation_plots.png` ($300\text{ DPI}$), and opens the interactive Matplotlib plot window.
